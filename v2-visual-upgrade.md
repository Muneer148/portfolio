# Visual Upgrade v2

This repository's next visual pass should transform the existing static portfolio into a polished, lightweight interactive site while preserving the factual content and static GitHub Pages deployment.

Recommended interactions:
- animated hero entrance
- subtle cursor-following glow on desktop
- animated background grid/noise
- scroll-triggered section reveals
- project cards with tilt/hover depth and clear CTA buttons
- active navigation indicator
- animated capability bars using qualitative levels (Core / Working / Exploring), not invented percentages
- project case-study transitions
- accessible focus states and prefers-reduced-motion fallback

Avoid:
- excessive particle effects
- fake AI terminal gimmicks
- fake proficiency percentages
- heavy WebGL that harms mobile performance
- autoplay audio
- excessive gradients/neon styling
