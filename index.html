03 / ENGINEERING NOTES

The work, unpacked.

Selected projects get more than a technology list: the goal is to show the problem, architecture, learning and limitations without pretending a student prototype is a production system.

01
JARVIS · AI SYSTEMS

Local-first assistant with controlled execution.

JARVIS explores an assistant architecture where the model decides what tool is needed while deterministic Python code performs the action. The project emphasizes a boundary between reasoning and execution.

Architecture

User → model/router → tool decision → Python tool → result → response.

Engineering idea

Plan and validate before execution; verify outcomes afterward and keep destructive actions behind approval.

Current limitation

This is an evolving personal project. Planned capabilities should not be read as already implemented.
