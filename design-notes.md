# Portfolio visual direction

The portfolio should feel like a polished interactive engineering portfolio rather than a plain static resume page.

Visual goals:
- dark editorial / technical aesthetic
- subtle animated grid/noise background
- scroll reveal and section transitions
- interactive project cards with hover depth
- compact animated skill/proficiency visualization based on honest categories, not fake percentages
- strong typography hierarchy
- responsive mobile navigation
- reduced-motion fallback
- fast static-site performance; no framework or backend required

Primary narrative:
Build → Learn → Validate → Improve.

Featured work: JARVIS, Depression Detection, TrendPulse, AI DataPilot.
