# Shaik Muneeruddin — Portfolio

Personal portfolio for **Shaik Muneeruddin**, a CSE (AI & ML) student building software, data systems and practical AI experiments.

## Run locally

No build step is required. Open `index.html` in a browser, or serve the directory with any static HTTP server.

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

The site is designed for GitHub Pages and requires no backend or paid service.

## Structure

- `index.html` — semantic page structure and content
- `styles.css` — responsive visual system
- `script.js` — small progressive-enhancement interactions
